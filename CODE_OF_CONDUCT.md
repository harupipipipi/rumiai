# Code of Conduct

Rumi AI welcomes contributors who want to build local-first AI tooling with careful security and review habits.

## Expected Behavior

- Be respectful and specific in issues, reviews, and discussions.
- Assume good intent while still asking for evidence, tests, and clear threat-model notes.
- Keep reports actionable: include context, reproduction steps, logs, and version information when possible.
- Respect user privacy and remove secrets, tokens, private prompts, personal data, and proprietary code before posting.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Posting private information without permission.
- Encouraging unsafe changes that bypass approval, audit, capability trust, workspace isolation, or secret-handling boundaries.
- Creating fake adoption signals, fake users, purchased engagement, or star-for-star campaigns.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code of conduct. Repeated or severe violations may result in blocking from the project.

For security-sensitive issues, follow [SECURITY.md](./SECURITY.md) instead of opening a public issue.
