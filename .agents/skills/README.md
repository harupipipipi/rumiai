# Rumi UI Compiler Skills

These skills are the instruction layer for the recursive UI compiler. Keep global repository rules in `AGENTS.md`; put role-specific design and proof workflow here.

- `rumi-ui-foundation`: generates independent foundation candidates.
- `rumi-ui-decomposer`: turns pages into bounded UI trees and contracts.
- `rumi-ui-leaf-builder`: builds one leaf candidate from a blank directory.
- `rumi-ui-composer`: wires accepted leaves into routes and pages without editing leaf internals.
- `rumi-ui-proof`: renders, inspects, and reports proof for candidates and pages.
