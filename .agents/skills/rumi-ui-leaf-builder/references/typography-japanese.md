# Japanese Typography Checks

- Validate long Japanese headings without inserting arbitrary font-size reductions.
- Prefer line breaks at phrase boundaries; avoid single-character orphan lines when a layout alternative is available.
- Mixed Japanese and alphanumeric text must keep Latin lowercase legible at the assigned type role.
- Numeric values should use the foundation numeric role and align tabularly when compared in rows.
- At 200% text scale, primary content and primary actions must remain reachable without horizontal scrolling.
