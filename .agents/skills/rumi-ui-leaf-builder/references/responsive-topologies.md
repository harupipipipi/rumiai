# Responsive Topologies

Do not compress desktop topology into mobile.

Inbox example:
- Desktop: list | thread | context
- Tablet: list | thread, context as drawer
- Mobile: conversation list route -> thread route, context as sheet

Responsive failure signals:
- desktop and mobile show the same high control count
- toolbar wraps into multiple crowded rows
- primary action moves offscreen
- unintended horizontal scroll appears
- cards become deeply stacked with no hierarchy
