# 提示 Linting 和 Compaction

及时的 linting 检测重复的部分、令牌预算压力以及必须保留的安全或权限文本。压缩建议较短的提示，同时保留提及安全、批准、权限、秘密或凭据的部分。

打包提示不会被破坏性地重写；消费者应将接受的建议存储在配置文件工作区配置中。
