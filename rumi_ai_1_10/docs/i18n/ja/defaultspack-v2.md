# デフォルトパック v2

このブランチは、defaultspack v2 互換性サーフェスを追加します。

- モジュール状態およびカタログヘルパー
- バックエンド/フロントエンドローダー
- セットアップ パックの選択 (スタートアップ インクルード プロンプト + 最初のオール OK 許可)
- AI クライアント、プロンプト、ツール、プラグイン、チャット、メモリ、エージェント、サンドボックス、移行用のシン アダプター

`supports_all_ok` は、`ecosystem/setup_pack/*` からの信頼されたリポジトリ メタデータです。
アップストリームでは、メンテナがレビューしたセットアップ パック定義のみが信頼されます。フォーク
独自のセットアップ パックを追加できます。これは、信頼できるソースを変更するのと同じです。
