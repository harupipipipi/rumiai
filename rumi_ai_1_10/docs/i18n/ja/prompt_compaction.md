# リンティングと圧縮を迅速に実行

迅速なリンティングにより、重複セクション、トークン予算のプレッシャー、保持する必要がある安全性や許可のテキストが検出されます。圧縮では、安全性、承認、権限、秘密、資格情報に言及するセクションを維持しながら、プロンプトを短くすることを提案します。

パックのプロンプトは破壊的に書き換えられることはありません。消費者は、受け入れられた提案をプロファイル ワークスペース設定に保存する必要があります。
