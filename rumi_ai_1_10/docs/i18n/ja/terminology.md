# 用語

この文書は、Rumi に推奨されるユーザー向け語彙を定義します。

これらの用語は、ドキュメント、UI コピー、および例で一貫して使用してください。下位レベルのランタイム
API 名は依然としてレガシーまたはトランスポート指向の識別子を使用する場合があります。
互換性が重要です。

## 優先用語

|用語 | |に使用します。メモ |
|---|---|---|
| `rule` |スコープ内でデフォルトで適用される常にロードされる命令。これは、ベースライン動作を表す主な製品用語です。 |
| `skill` |トリガーまたはオンデマンドの命令/ワークフロー バンドル |関連する場合にアクティブ化される、集中的な機能バンドルに使用します。 |
| `prompt` |実行時に組み立てられる生のモデル入力テキスト |これをユーザー向けの主要な概念ではなく、実行時の成果物として扱います。 |
| `system prompt` |モデル API に送信される低レベルのシステム ロール プロンプト ペイロード |トランスポート層自体が主題でない限り、ユーザー向けの説明では `rule` または `skill` を優先します。 |
| `team workspace` |複数のエージェントが調整する 1 つのユーザー向けワークスペース |新しいドキュメントと UI コピーでは、`company workspace` よりもこれを優先します。 |
| `team` |協力するエージェントのセット |ストレージ層やルーティング層ではなく、グループを説明するときに使用します。 |
| `agent` |ツール対応のランタイム アクター |これは引き続き一般的な実行単位です。 |
| `specialist` |狭い範囲のエージェント定義または役割 |再利用可能なワーカー ロールに名前を付ける場合は、`subagent` よりもこれを優先します。 |
| `delegation` |制限された作業を別のエージェントに送信する行為 |正規の `agent.delegate` ランタイム動作にマップします。 |
| `tool` |エージェントが呼び出すことができる外部アクションまたは統合 |この意味は狭く、具体的なものにしてください。 |
| `pack` |コード、アセット、ルート、プロンプト、ツール、またはスキルを提供する、出荷されたランタイム/パッケージ ユニット |これを、`rule` などの命令層の用語とは別にしてください。 |

## 互換性条件

|互換性用語 |優先用語 |それについてどう話すか |
|---|---|---|
| `company` / `company workspace` | `team` / `team workspace` | `company` は、ランタイム API、保存された識別子、または従来のドキュメントでまだ使用されている場合にのみ保持してください。 |
| `subagent` | `specialist` または `delegated agent` | `subagent` を古いルート、ツール、ドキュメントの互換性エイリアスとして保持します。 |
|製品コンセプトとしての`system prompt` | `rule` / `skill` | `system prompt` は、モデル トランスポートまたはプロバイダー API について説明する場合にのみ使用してください。 |

## 重要な曖昧さ回避: `rule` と `pack_type: "rule"`

Rumi は現在、`rule` という単語を 2 つの異なる用途で使用しています。

1. 命令層 `rule`
   エージェントの動作に関して常にロードされる命令を意味する場合にこれを使用します。
2. パッケージング/ランタイム `pack_type: "rule"`
   これは、内部パックの分類またはマニフェスト/ランタイムの概念を意味する場合にのみ使用してください。

これらは名前のみで関連しています。パッケージ化/ランタイム `rule` は自動的には実行されません。
命令層 `rule` と同じもので、どの層がどの層であるかをドキュメントに記載する必要があります。
曖昧な可能性がある場合は常に議論されます。

## ライティングガイダンス

- `rule = always on`を好みます。
- `skill = triggered or on demand`を好みます。
- 長時間実行されるマルチエージェント サーフェスには、`team workspace` を優先します。
- ランタイム アクションには `delegation` を、ワーカー ロールには `specialist` を優先します。
- 実装、ランタイム、または API の詳細については、`prompt` および `system prompt` を参照してください。
