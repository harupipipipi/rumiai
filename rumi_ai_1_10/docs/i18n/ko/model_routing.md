# 모델 라우팅

모델 라우팅은 사용자가 선호하는 모델 그룹부터 시작하여 이미지, 파일, 요청 도구, 요청 사고 수준, 속도 힌트, 실용 신안 설정을 확인합니다.

라우터는 `selected_model`, `original_model`, `selected_group`, `reason_codes`, `warnings`, `bridge_required`, `bridge_plan` 및 `utility_models`을 반환합니다. 도구 선택은 여전히 ​​권고 사항입니다. 기존 권한 및 부여 확인은 여전히 ​​최종 권한입니다.
