# 모델 기능

Defaultspack은 라우팅 중심 기능 필드로 공급자 및 프로필 카탈로그를 강화합니다. 점수는 절대적인 모델 순위가 아닌 의도적으로 루미아이 라우팅을 기준으로 합니다.

주요 필드: `supports_vision`, `supports_tool_calling`, `supports_thinking`, `thinking_levels`, `supports_fast`, `speed_tier`, `quality_tier`, `knowledge_level`, `knowledge_band`, `capability_tags`, `allowed_roles`, `recommended_roles`.

`defaults.ai.search_models`로 검색하고 `defaults.ai.get_model_capabilities`으로 하나의 모델을 검사합니다.
