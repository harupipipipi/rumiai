# 도구 저작

도구에는 매니페스트, 호출 가능한 함수 또는 도구 진입점, 위험 수준, 권한 요구 사항, UI 메타데이터 및 모델 호환성 참고 사항이 필요합니다.

기능 블록은 내부 호출 가능 단위입니다. 도구는 사용자에게 표시되는 기능을 노출하며 도구 호출 모델에 의해 호출될 수 있습니다. 고위험 도구에는 파일 쓰기, 삭제, 터미널 실행, 네트워크 변형, 브라우저/컴퓨터 제어 및 자격 증명 변경이 포함됩니다.

도구 매니페스트에는 필수 권한, 승인 요구 사항, 입력/출력 스키마 및 UI 레이블이 명시되어야 합니다. AI 요청이 구축되기 전에 선택한 모델 기능에 대해 도구 호출 호환성을 확인해야 합니다.
