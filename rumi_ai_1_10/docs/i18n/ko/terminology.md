# 용어

이 문서는 Rumi에서 사용자가 선호하는 어휘를 정의합니다.

문서, UI 문구, 예시에서 이러한 용어를 일관되게 사용하세요. 하위 수준 런타임
API 이름은 여전히 레거시 또는 전송 지향 식별자를 사용할 수 있습니다.
호환성이 중요합니다.

## 선호 용어

| 기간 | 다음 용도로 사용 | 메모 |
|---|---|---|
| `rule` | 범위 내에서 기본적으로 적용되는 항상 로드되는 명령어 | 이는 기본 동작을 나타내는 주요 제품 용어입니다. |
| `skill` | 트리거 또는 주문형 지침/워크플로 번들 | 관련될 때 활성화되는 집중된 기능 번들에 사용합니다. |
| `prompt` | 실행 시 수집된 원시 모델 입력 텍스트 | 이를 기본 사용자 대상 개념이 아닌 런타임 아티팩트로 취급하십시오. |
| `system prompt` | 모델 API로 전송된 하위 수준 시스템 역할 프롬프트 페이로드 | 전송 계층 자체가 주제가 아닌 한 사용자 대상 설명에서는 `rule` 또는 `skill`를 선호합니다. |
| `team workspace` | 여러 상담원이 협력하는 하나의 사용자 대면 작업 공간 | 새 문서 및 UI 사본에서는 `company workspace`보다 이를 선호합니다. |
| `team` | 협력 에이전트 세트 | 스토리지 또는 라우팅 계층이 아닌 그룹을 설명할 때 사용합니다. |
| `agent` | 도구를 사용할 수 있는 런타임 행위자 | 이는 일반 실행 단위로 남아 있습니다. |
| `specialist` | 좁은 범위의 상담원 정의 또는 역할 | 재사용 가능한 작업자 역할의 이름을 지정할 때 `subagent`보다 이를 선호합니다. |
| `delegation` | 제한된 작업을 다른 에이전트에게 보내는 행위 | 표준 `agent.delegate` 런타임 동작에 매핑됩니다. |
| `tool` | 에이전트가 호출할 수 있는 외부 작업 또는 통합 | 이 의미를 좁고 구체적으로 유지하십시오. |
| `pack` | 코드, 자산, 경로, 프롬프트, 도구 또는 기술을 제공하는 제공된 런타임/패키지 단위 | 이를 `rule`과 같은 명령어 계층 용어와 별도로 유지하세요. |

## 호환성 조건

| 호환성 용어 | 선호하는 용어 | 그것에 대해 이야기하는 방법 |
|---|---|---|
| `company` / `company workspace` | `team` / `team workspace` | 런타임 API, 저장된 식별자 또는 레거시 문서에서 계속 사용하는 경우에만 `company`를 유지하세요. |
| `subagent` | `specialist` 또는 `delegated agent` | `subagent`를 이전 경로, 도구 및 문서에 대한 호환성 별칭으로 유지하세요. |
| `system prompt` 제품 컨셉 | `rule` / `skill` | 모델 전송 또는 공급자 API를 논의할 때만 `system prompt`을 사용하십시오. |

## 중요한 명확성: `rule` 대 `pack_type: "rule"`

루미는 현재 `rule`라는 단어를 두 가지 다른 용도로 사용하고 있습니다.

1. 명령어 계층 `rule`
   에이전트 동작에 대해 항상 로드되는 명령을 의미하는 경우 이를 사용합니다.
2. 패키징/런타임 `pack_type: "rule"`
   내부 팩 분류 또는 매니페스트/런타임 개념을 의미하는 경우에만 이를 사용하십시오.

이들은 이름으로만 관련되어 있습니다. 패키징/런타임 `rule`은 자동으로 실행되지 않습니다.
명령 계층 `rule`과 동일하며 문서에서는 어떤 계층이
모호함이 가능할 때마다 논의됩니다.

## 작성 지침

- `rule = always on`을 선호합니다.
- `skill = triggered or on demand`을 선호합니다.
- 장기간 실행되는 다중 에이전트 표면에는 `team workspace`를 선호합니다.
- 런타임 작업의 경우 `delegation`를 선호하고 작업자 역할의 경우 `specialist`을 선호합니다.
- 구현, 런타임 또는 API 세부정보를 위해 `prompt` 및 `system prompt`을 예약하세요.
