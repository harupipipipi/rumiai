# 핵심 제어판

이 패널의 정식 프런트엔드 소스는 `../../../../../rumi_viewer/frontend`에 있습니다.

이 팩은 `web/`의 `/panel`에 구축된 정적 아티팩트를 제공합니다. 브라우저 경로(`http://127.0.0.1:8765/panel/`)와 Rumi Viewer 부트스트랩 흐름 모두 동일한 아티팩트를 사용합니다.

Tauri `splash` 화면은 별도로 유지되며 커널이 준비되기 전에만 사용됩니다.
