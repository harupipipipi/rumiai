# Rumi Browser Element Pack

Rumi Browser Element Pack packages browser-use style element recognition around the bundled Rumi Browser Companion extension. It does not add a second browser controller. It gives agents profiles, prompts, presets, and a shared schema for working with semantic DOM snapshots, highlighted evidence, and element actions.

## What It Provides

- Semantic DOM profile for pages opened in the user's real Chromium profile.
- Browser-use inspired operating preset: inspect, rank elements, highlight evidence, act, then verify.
- Element schema covering accessible names, labels, nearby text, geometry, action hints, and selectors.
- Examples for inspection, form filling, extraction, and visual grounding.

## What It Does Not Provide

- A separate extension bundle.
- Unapproved browser automation.
- Vendor-hosted browsing or remote session replay.
