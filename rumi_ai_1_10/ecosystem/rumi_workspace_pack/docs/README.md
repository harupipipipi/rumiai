# Rumi Workspace Pack Docs

This directory describes the `rumi_workspace_pack` contract and operating model.

## Reading Guide

- [architecture.md](architecture.md): responsibilities, directories, execution path, and runtime touch points.
- [interfaces.md](interfaces.md): profiles, prompts, catalogs, grants, network posture, stores, and required secrets.
- [operations.md](operations.md): development workflow, test commands, common failure modes, and review checks.

For a quick overview, read the pack-level [README.md](../README.md) first, then use `interfaces.md` when wiring runtime implementations to this pack.
