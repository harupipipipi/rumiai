defaultspack shell

既存 shell を維持したまま、provider・profile・tool・MCP・接続状態を見やすくした密度高めの UI です。

会話とモデル 現在のタブごとに model・provider・profile 推定を右パネルと下部メタで確認できます。
接続の見える化 `/api/health` と `/api/context` を分けて扱い、片方だけ落ちても状況が分かるようにしています。
Settings 実データ対応 利用可能なら `/api/container/settings` を読み込み、operator mode とモデル設定を編集できます。
Graceful fallback profiles や operator settings が未実装でも UI は壊れず、未提供として表示されます。
