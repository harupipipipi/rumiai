# Research Agent Design

Research is local-first.

Objects:

- source card: local file, note, web archive, official doc, GitHub, Reddit, or web.
- claim: statement, source refs, confidence, and caveats.
- citation: stable reference to source path or URL.
- comparison table: structured rows and columns.

Official docs are preferred for factual claims. Reddit-like sources are user voice only. Web, browser, and Reddit providers are optional.
