# 브라우저 컴퓨터 사용 옵션 디자인

브라우저 및 컴퓨터 사용은 선택 사항입니다.

운영:

- 브라우저 열기
- 스크린샷
- 클릭, 입력, 키, 스크롤
- 텍스트 추출
- 다운로드
- 세션 저장 및 복원
- 창 범위 컨텍스트 및 스크린샷
- 중단 없는 이동/클릭 마커를 위한 가상 AI 커서
- 자동 텍스트/키 드라이버 전환:
  - 명시적으로 요청된 경우 Chrome DOM 백그라운드 항목
  - 사용자가 오버랩을 허용할 때 전경 키보드 대체
  - Chrome이 아닌 앱에 대한 일반적인 포그라운드 데스크톱 작업

네트워크 탐색, 다운로드 및 외부 사이트 상호 작용에는 승인과 감사가 필요합니다. 핵심 카탈로그는 이 기능을 설명하지만 브라우저 공급자가 필요하지 않습니다.
