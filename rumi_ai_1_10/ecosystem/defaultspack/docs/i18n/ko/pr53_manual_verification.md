# PR #53 후속 매뉴얼 검증

defaultspack webapp을 시작한 후 브라우저 UI를 사용하십시오.

- 좁은 너비 및 일반 너비: 작곡가 `+` 메뉴가 열리고 뷰포트 내에 유지되며 배경에서 닫힙니다.
- 파일 첨부: 파일을 선택하면 작성기에 첨부 칩이 추가됩니다.
- 슬래시 명령: `/coding`을 입력하면 해당 명령을 사용할 수 있는 경우 코딩 흐름/모드로 전환됩니다.
- 코딩 바닥글: 브랜치, 작업공간 루트 및 선택한 파일이 코딩 바닥글에 표시됩니다.
- 코딩 바닥글: 바닥글에서 대상 폴더 변경, 브랜치 선택, 새로운 브랜치 생성이 가능합니다.
- 코딩 `@file`: `/coding`에 `@README.md`를 입력하고 파일을 선택합니다. 멘션은 입력에 남아 있고 작업 공간 부착 칩/카드가 나타납니다.
- 작업공간 첨부: 선택한 텍스트 파일을 보내면 백엔드 사용자 메시지 내용에 파일 본문이 저장됩니다. 바이너리 또는 메타데이터 전용 첨부 파일은 메타데이터 전용으로 유지됩니다.
- 첨부만 보내기: 텍스트 파일을 첨부하고 텍스트 입력란을 비워둔 후 보냅니다. 메시지가 승인되고 백엔드 사용자 콘텐츠에 첨부 파일 텍스트가 포함됩니다.
- 사이드바 드래그/드롭:
  - `composer.toggle_chip`을 선언하는 `tool_toggle` 위젯은 컴포저 칩이 되며 켜기/끄기로 전환할 수 있습니다.
  - `composer.action_button`을 선언하는 `button` 위젯은 작곡가 액션 칩이 됩니다. `requires_approval: false`를 사용한 안전한 동일 출처 `/api/` 작업은 미리보기에 결과를 표시합니다.
  - `composer.open_panel`을 선언하는 `panel` 위젯은 작성기 칩이 되고 일치하는 사이드바 패널을 엽니다.
- `composer.selector_chip`을 선언하는 `selector` 위젯은 선택기 칩으로 허용됩니다. 현재 최소 동작은 패널/작업 대상을 열 수 있습니다.
  - 지원되지 않는 위젯 종류, 누락된 기능, 외부 엔드포인트, 승인이 필요한 작업은 무시되거나 차단됩니다.
- 선택된 도구: 선택된 도구 ID는 제공자 도구 적응 전에 `ToolRegistry`를 통해 확인됩니다. 원시 문자열은 공급자 `tools`에 표시되어서는 안 됩니다.
