# Rumi AI OS 기본값 충돌 해결

Rumi AI OS 생태계가 성장함에 따라 여러 팩이 필연적으로 유사한 기능(예: `tool_search`, `file_editor`)을 제공하게 됩니다. 이 문서에서는 `defaults` 팩이 이름 충돌, 사용자 기본 설정 및 보안 기능 가져오기를 처리하여 안정성을 보장하고 악의적인 하이재킹을 방지하는 방법을 자세히 설명합니다.

## 충돌 이름 지정

두 개 이상의 설치된 팩이 동일한 식별자를 사용하여 엔터티(도구, 흐름, 에이전트)를 선언하는 경우 시스템은 충돌 없이 이를 안정적으로 해결해야 합니다.

### 1. 선호 계층 구조(우선순위 규칙)
핵심 엔진은 다음과 같은 엄격한 우선순위에 따라 이름을 확인합니다.
1. **사용자 재정의(`user_data/preferences.json`):** 사용자가 식별자를 특정 팩(예: `"search_tool": "com.example.advanced_search"`)에 명시적으로 매핑하는 경우 절대적으로 승리합니다.
2. **명시적 팩 접두사:** 팩은 내부적으로 식별자 앞에 접두사를 붙여야 하지만 구성 요소는 짧은 이름으로 호출될 수 있습니다. 충돌이 있는 경우 호출자는 정규화된 이름을 사용해야 합니다(예: `rumi.tools.search` 대 `my_company.tools.search`).
3. **설치된 팩 우선순위:** `defaults` 팩은 설치된 팩을 관리하기 위한 UI를 제공합니다. 사용자는 글로벌 "Pack Priority Order"를 설정할 수 있습니다. 팩 A의 우선순위가 팩 B보다 높으면 팩 A의 도구가 우선합니다.
4. **내장된 기본 대체:** 요청한 구성 요소가 누락되거나 오류가 발생하는 경우 코어 시스템은 `defaults` 팩 구현으로 대체됩니다.

### 2. 모호성에 대한 사용자 프롬프트
에이전트가 `calculator`라는 도구를 호출하려고 시도하고 `pack_a` 및 `pack_b` 모두 명확한 우선순위 규칙 세트 없이 *없이* 이 도구를 제공하는 경우 다음이 발생합니다.
* `defaults` 팩은 실행 흐름을 일시 중지합니다.
* 사용자에게 선호하는 구현을 선택하고 이를 규칙으로 저장하도록 요청하는 UI 모달 팝업이 나타납니다.
    * *프롬프트:* "팩 A와 팩 B 모두 '계산기'를 제공합니다. 이 요청에 어느 것을 사용해야 합니까, 아니면 영구적으로 사용해야 합니까?"

## 가져오기 권한

Rumi AI OS는 Python 라이브러리 및 기타 팩을 사용합니다. "악의 가정" 원칙을 준수하려면 팩 수입을 엄격하게 통제해야 합니다.

### 1. 샌드박스 제한 사항
팩은 격리된 환경에서 실행됩니다. 단순히 `import os` 또는 `require('fs')`를 느슨하게 할 수는 없습니다.

### 2. 수입 보조금으로서의 역량
핵심 OS 문서에 설명된 대로 기능을 가져오거나 시스템 리소스에 액세스하려면 기능 부여가 필요합니다. `defaults` 팩은 이 요청에 대한 UI를 관리합니다.
* **액세스 요청:** 팩이 처음으로 설치되거나 실행될 때 `ecosystem.json`에서 필수 기능을 선언합니다(예: `rumi.fs.read`, `external.python.requests`).
* **승인 흐름:** `defaults` 팩은 사용자 승인 대화 상자를 처리합니다. 사용자에게는 팩이 원하는 정확한 *무엇*과 *이유*가 제시됩니다.
    * 부여된 경우 시스템은 직접 코드 실행 권한이 아닌 송신 프록시 또는 특수 소켓을 프로비저닝합니다.
    * 거부된 경우 팩은 "fail-soft"여야 합니다. 즉, 가장 중요한 애플리케이션(예: 채팅 흐름)이 경고 메시지와 함께 충돌 없이 계속됨을 의미합니다.

### 3. Pack-to-Pack 가져오기(종속성 해결)
`pack_a`가 `defaults` 또는 `pack_b`의 함수를 사용하려는 경우 종속성 해결 메커니즘을 따릅니다.
* **승인:** 사용자는 `pack_a`가 `pack_b`의 공개 인터페이스를 호출할 수 있도록 허용하여 하나의 팩이 다른 악의적인 작업을 눈에 보이지 않게 조율할 수 없도록 승인해야 합니다.
