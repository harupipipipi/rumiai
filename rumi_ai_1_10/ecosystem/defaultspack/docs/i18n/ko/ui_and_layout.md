# Rumi AI OS 기본 UI 및 레이아웃

이 문서에서는 `defaults` 팩에서 제공하는 UI 구성 요소에 대한 디자인 원칙과 기대 사항을 자세히 설명하며, 특히 사용자 정의, 드래그 앤 드롭 기능 및 동적 도구 표시에 대한 요구 사항을 다루고 있습니다.

## 핵심 UI 철학: 자산을 통한 유연성

Rumi AI OS 프런트엔드는 단일 애플리케이션이 아닙니다. 이는 팩에서 제공하는 "자산"의 집합체입니다. `defaults` 팩은 표준 그리드 및 상호 작용 모델을 설정하지만 거의 모든 요소를 ​​교체할 수 있습니다.

### 자산 기반 UI 레지스트리
1. **프런트엔드/백엔드 분리:** 백엔드는 논리, 흐름 실행 및 데이터 저장을 처리합니다. 프런트엔드는 팩에 등록된 자산 렌더링을 전담적으로 담당합니다.
2. **자산 카탈로그:** 팩은 `assets` 배열 아래의 `ecosystem.json`에서 UI 구성 요소(예: 사용자 정의 채팅 창, 새로운 입력 스타일 또는 설정 패널)를 정의합니다.
3. **UI 설정 팩:** 일반 레이아웃 자산(예: "전체 화면 레이아웃", "사이드바 오버레이")을 선언하는 개념적 또는 리터럴 팩(예: `settings_pack`)을 설치할 수 있습니다. `defaults` 팩은 기준선 그리드를 제공합니다.

## 드래그 앤 드롭 아키텍처

임의 배치 요구 사항을 충족하려면(예: 채팅 창 또는 입력 필드를 자유롭게 배치):

1. **캔버스 컨테이너:** 기본 UI는 "캔버스"로 간주됩니다.
2. **드래그 가능한 구성 요소:** 기본 팩의 핵심 입력 및 출력(채팅 스트림, 입력 표시줄, 도구 상태)은 드래그 가능한 자산 컨테이너에 래핑됩니다.
3. **위치 지속성:** 사용자가 구성요소를 이동하면 새로운 `(x, y)` 또는 `grid-area` 좌표가 사용자의 `user_data` 디렉토리에 있는 `ui_preferences.json`에 저장됩니다. `defaults` 팩은 다시 로드할 때 이러한 좌표를 따릅니다.

## 동적 도구 표시 및 설정

도구는 AI가 현재 무엇을 하고 있는지 사용자에게 알려야 합니다.

### 1. 도구 사이드바(활동 로그)
* **목적:** `defaults` 팩에는 표준 사이드바 활동 로그가 포함되어 있습니다.
* **등록:** AI 에이전트가 Flow Engine을 통해 도구를 실행하면 백엔드에서 UI 이벤트를 생성합니다. 사이드바는 이러한 이벤트를 수신하고 실시간 실행 상태를 표시합니다(예: "웹에서 'Python 라이브러리' 검색 중...", "`config.yaml` 읽기..." 읽기).
* **가시성:** 이를 통해 사용자는 주요 대화 스트림을 복잡하게 하지 않고도 AI의 현재 컨텍스트를 이해할 수 있습니다.

### 2. 사용자 정의 도구 표시(ToolDisplay 자산)
일부 도구에는 단순한 텍스트 로그 이상이 필요합니다(예: 데이터 시각화 도구, 이미지 생성기).
* **`tooldisplay` 등록:** 도구 팩은 `type: tooldisplay` 태그가 지정된 특정 프런트엔드 자산(React 구성 요소 또는 웹 구성 요소)을 등록할 수 있습니다.
* **동적 주입:** 해당 도구가 실행되면 `defaults` 팩의 UI 조정자가 이 사용자 정의 자산을 활성 도구 영역(종종 모달 또는 전용 분할 창)에 동적으로 주입합니다.

### 3. 도구 설정(ToolSetting Assets)
사용자는 도구를 구성해야 합니다(예: API 키 입력, 검색 기본 설정 지정).
* **`toolsetting` 등록:** 도구 팩은 해당 설정에 대한 JSON 스키마 또는 사용자 정의 UI 자산을 제공합니다.
* **자동 UI 생성:** 기본적으로 스키마만 제공되는 경우 `defaults` 팩은 스키마 유형에 따라 설정 양식(입력, 토글)을 자동으로 생성합니다. 사용자 정의 자산이 제공되면 해당 자산이 대신 렌더링됩니다. 이는 "도구" 카테고리 아래의 기본 설정 패널을 통해 액세스할 수 있습니다.

## 애니메이션 표준화

서로 다른 팩 간의 시각적 충돌을 방지하려면 다음을 수행하십시오.

1. **애니메이션 상수:** `defaults` 팩은 전환을 위한 표준 CSS 변수를 정의합니다(예: `--rumi-anim-fast: 150ms ease`, `--rumi-anim-medium: 300ms ease-in-out`).
2. **지침:** 팩 개발자는 문서를 통해 도구 표시 및 사용자 정의 UI 자산에 이러한 변수를 활용하여 응집력 있는 환경을 유지하도록 적극 권장됩니다.

## 대체 메커니즘

사용자 정의 UI 자산이 로드되지 않거나 오류가 발생하는 경우:
1. **페일 소프트 렌더링:** `defaults` 팩은 오류를 포착하고, 문제가 되는 구성 요소를 화면에서 제거하고, 간단한 오류 경계 블록을 렌더링하여 나머지 OS(예: 핵심 채팅)가 계속 작동하도록 합니다.
