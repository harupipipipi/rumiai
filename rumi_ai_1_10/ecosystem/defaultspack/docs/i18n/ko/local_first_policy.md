# 지역 우선 정책

defaultspack 코어는 클라우드 API 키 없이 사용할 수 있습니다.

이 저장소의 정식 구현은 다음과 같습니다.
§루미§0§. 이전 `ecosystem/defaults/` 패키지
별도의 `harupipipipi/rumiai_defaults` 저장소는 호환성이 있거나
스냅샷 소스. 새로운 런타임 동작, 안전 규칙, 경로 계약 및 UI
기본값은 defaultspack에서 먼저 구현되어야 하며 레거시 별칭은 그대로 유지됩니다.
기존 발신자가 여전히 필요한 경우에만.

정책:

- 팩이 명시적으로 더 광범위한 기능을 부여하지 않는 한 작업 공간 파일만 해당됩니다.
- 네트워크는 기본적으로 거부됩니다.
- 클라우드 모델 공급자는 선택적 어댑터입니다.
- 파일 쓰기, 덮어쓰기, 삭제, 터미널 실행, git push에는 승인 메타데이터가 필요합니다.
- 비밀은 Rumi 비밀 저장소에 저장되며 UI 카탈로그에는 절대 노출되지 않습니다.
- 감사 기록에는 조치, 위험, 결정 및 수정된 주장이 포함됩니다.

코어에는 로컬 파일, 터미널, Git, 로컬 모델 공급자 인터페이스, 메모리, 프로젝트, 컴팩트, 아티팩트, 안전, 권한 및 감사가 포함될 수 있습니다. 외부 검색, Reddit, 브라우저 네트워크, GitHub API, SaaS 통합 및 클라우드 일정은 선택 사항으로 유지됩니다.

## 런타임 기본값

- 보장된 시작 모델은 `stub/default`입니다.
- Ollama, LM Studio, vLLM, llama.cpp 및 local과 같은 로컬 공급자
  외부 네트워크를 만들지 않고도 OpenAI 호환 엔드포인트를 감지할 수 있습니다.
  요청.
- 클라우드 제공자는 카탈로그 항목 및 구성 대상이지만
  새로운 런타임 기본값으로 선택되지 않았습니다.
- 런타임 시 자동 클라우드 공급자 등록은 다음과 같은 경우가 아니면 비활성화됩니다.
  프로세스는 `RUMI_DEFAULTSPACK_ENABLE_CLOUD_PROVIDERS`를 통해 명시적으로 동의합니다.
- 로컬 공급자는 API 키가 필요하지 않습니다. API 키 프롬프트만 표시되어야 합니다.
  클라우드 공급자 또는 클라우드 모델을 선택한 후.

## 로컬 작업 보호

민감한 로컬 작업은 사용자 계정과 별도로 보호됩니다. 이
사이트 간 또는 오래된 탭 변형 시도로부터 로컬 HTTP 런타임을 보호합니다.
로그인, 계정 생성, Supabase 또는 Cloudflare 종속성을 추가하지 않고.

민감한 변형에는 파일 쓰기/생성/삭제/패치/복원, 터미널이 포함됩니다.
실행/스트리밍, git 커밋/푸시, 통합 비밀 및 브라우저
스크린샷. 실행하기 전에 다음 검사를 통과해야 합니다.

- 클라이언트 주소가 루프백입니다.
- Origin 헤더가 있는 경우 로컬 헤더입니다.
- 기원이 있는 민감한 돌연변이에는 `X-Rumi-CSRF`이 포함됩니다.
- 블록은 작업에 바인딩된 서명된 일회성 승인 토큰을 받습니다.
  인수 해시;
- 시도, 승인 결정, 실행, 거부 또는 실패가 기록됩니다.
  비밀이 수정된 JSONL 감사 로그입니다.
