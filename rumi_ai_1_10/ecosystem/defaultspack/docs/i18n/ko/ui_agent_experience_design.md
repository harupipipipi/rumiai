# UI 에이전트 경험 디자인

UI는 부품으로 제작된 교체 가능한 쉘입니다.

예상 패널:

- 채팅
- 계획
- 도구 호출
- 파일 트리
- 차이점 뷰어
- 터미널
- 유물
- 기억
- 프로젝트 설정
- 승인 대화상자
- 모델 선택기
- 컴팩트 버튼
- 실행 기록
- 소스 카드

프런트엔드는 카탈로그 API로부터 기능, 렌더러, 설정, 모델, 도구 및 계정 메타데이터를 수신합니다. 팩 내부를 하드 코딩해서는 안 됩니다.
