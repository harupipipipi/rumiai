# 안전 허가 감사 설계

안전 기본 요소:

- 권한 카탈로그
- 허용, 질문, 거부 정책
- 위험 분류
- 승인 게이트
- 작업공간 루트 시행
- 기본적으로 네트워크 거부
- 비밀 편집
- 감사 로그

감사 기록에는 타임스탬프, 행위자, 기능, 작업, 위험 수준, 결정 및 수정된 인수가 포함됩니다. 비밀 값은 감사 레코드에 기록되지 않습니다.

## 로컬 가드 구현

defaultspack은 이제 로컬 코딩 경로를 민감한 HTTP 작업으로 처리합니다. 는
Guard는 사용자 인증이 아닌 로컬 작업 보호입니다.

HTTP 전송은 루프백 클라이언트, 로컬 원본, CSRF 메타데이터를 확인합니다.
Origin 헤더를 포함하는 민감한 변형 및 경로별 민감도.
그런 다음 코딩 블록은 쓰기를 수행하기 전에 서명된 승인 토큰을 확인합니다.
파괴적인 파일 작업, 터미널 중간/고위험 실행, git 커밋 또는
힘내세요.

승인 토큰은 로컬 런타임 비밀로 서명된 HMAC입니다. 각 토큰은 바인딩되어 있습니다.
에:

- 작업 이름
- 승인된 인수의 안정적인 해시
- 승인 요청 ID
- 만료 타임스탬프.

토큰은 일회용입니다. UI 또는 호출자가 경로를 변경하는 경우 명령, git
승인, 실행 후 대상, 파일 콘텐츠 또는 기타 보호된 인수
거부되고 실패가 기록됩니다.

## 감사 저장

로컬 감사 저장소는 JSONL입니다. 기본적으로 아래에 기록됩니다.
§루미§0§; 테스트 또는 임베디드
런타임은 `RUMI_DEFAULTSPACK_AUDIT_PATH`으로 경로를 재정의할 수 있습니다.

감사 계층은 다음을 기록합니다.

- 시도;
- 승인 생성 및 결정
- 실행;
- 거부;
- 실패.

인수는 지속성 전에 수정됩니다. `api_key`이 포함된 키,
`authorization`, `token`, `secret`, `password` 또는 `cookie`가
중첩된 사전 및 목록을 포함한 교정 마커.
