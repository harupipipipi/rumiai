# AI 클라이언트 디자인

defaultspack AI 클라이언트는 흐름과 모델 제공자 간의 경계입니다. 그것
모델 선택, 공급자 자격 증명, 요청 구성을 정규화합니다.
스트리밍 이벤트 및 공급자 응답. 프롬프트, 도구, 메모리를 소유하지 않습니다.
또는 UI 동작; 이는 호출 흐름 및 프로필 작업 공간에서 제공됩니다.

## 책임

- 요청된 모델 프로필을 공급자, 모델 ID, 기능 메타데이터로 확인합니다.
  그리고 런타임 설정.
- 정규화된 메시지, 도구 스키마, 첨부 파일로부터 공급자 요청 작성
  업스트림 블록에서 제공하는 매개변수.
- 호출을 공급자 어댑터로 라우팅하고 정규화된 완료 결과를 반환합니다.
- 스트리밍 델타를 채팅 및 UI 레이어에서 사용할 수 있는 안정적인 이벤트 이름으로 정규화합니다.
  소비하다.
- 기존 공급자 키 저장소에 API 키를 유지합니다. 모델 프로필 및 문서는 다음과 같습니다.
  비밀을 포함하지 마세요.

## 책임 없음

- 프롬프트 저작과 프롬프트 변이는 프롬프트 레이어에 속합니다.
- 도구 검색, 권한 필터링, 승인 처리는 도구에 속하며,
  AI 요청이 구축되기 전의 권한 블록입니다.
- 흐름 오케스트레이션은 흐름 엔진에 속합니다.
- UI 위젯 및 애니메이션은 모델/프로필 UI 메타데이터 또는 프런트엔드에 속합니다.
  렌더러. AI 클라이언트는 메타데이터를 전달할 수 있습니다. 그것은 정의해서는 안됩니다
  제품 경험.

## 계약요청

`defaults.ai.build_request`는 다음에 의해 소비되는 정규화된 요청을 생성합니다.
`defaults.ai.complete`:

```json
{
  "conversation_id": "c1",
  "model": "stub/default",
  "messages": [
    {"role": "system", "content": "profile-scoped prompt"},
    {"role": "user", "content": "hello"}
  ],
  "tools": [],
  "params": {}
}
```

호출자는 효과적인 시스템 프롬프트를 전달할 책임이 있으며 이미
필터링된 도구. AI 클라이언트는 이러한 입력을 이유가 아닌 데이터로 처리해야 합니다.
프롬프트/도구 저장소를 읽거나 변경합니다.

## 모델 프로필

모델 프로필은 다음과 같은 공급자별 모델 및 기능을 식별합니다.
비전, 도구 호출, 사고 지원, 상황 제한 및 라우팅 힌트.
입력에 필요한 경우 라우팅에서 다른 모델 프로필을 권장할 수 있습니다.
선택한 프로필에는 부족한 기능이 있습니다. 공급자 키는 프로필 외부에 유지됩니다.
문서.

## 공급자 검색

공급자 검색은 매니페스트 우선입니다. OpenAI 호환 공급자 추가 가능
`extensions/llm/providers/<provider_id>/manifest.json` 플러스 포함
`models/*.json`; 런타임은 그로부터 `OpenAICompatibleProvider`를 인스턴스화합니다.
자격 증명이 구성되면 매니페스트됩니다. 사용자 정의 공급자 프로토콜은 여전히
명시적인 Python 진입점을 사용합니다.

선별된 공급자 메타데이터는 대체 호환성 데이터입니다. 유산을 채울 수도 있습니다
표시 이름 또는 기본값이지만 매니페스트 및 모델 정의는 표준입니다.
새로운 공급자에 대한 소스입니다.

## 스트리밍 이벤트

공급자별 스트리밍 청크는 채팅/UI에 도달하기 전에 정규화됩니다.
소비자. 일반적인 이벤트 이름은 다음과 같습니다.

- `message_start`
- `thinking_start`
- `thinking_delta`
- `thinking_end`
- `content_start`
- `content_delta`
- `tool_call_start`
- `tool_call_delta`
- `tool_call_end`
- `message_end`
- `error`

이벤트 페이로드는 유용한 경우 메타데이터 아래에 공급자 세부 정보를 보존해야 하지만
최상위 이벤트 이름과 텍스트/도구 필드는 공급자 중립성을 유지해야 합니다.

## 프로필 UI 메타데이터

모델 프로필이 `ui/events.ui.yaml`와 같은 선택적 UI 메타데이터를 제공하는 경우
스트리밍 레이어는 해결된 위젯 힌트를 정규화된 이벤트 페이로드에 첨부할 수 있습니다.
이는 통과 계약입니다.

- 파일은 선택사항입니다.
- 누락된 메타데이터는 기존 스트리밍 동작을 보존해야 합니다.
- 템플릿은 현재 이벤트 데이터에서 해결될 수 있습니다.
- 프론트엔드 렌더러는 위젯 힌트를 사용할지 무시할지 결정합니다.

AI 클라이언트는 "Thinking..."과 같은 하드코딩된 애니메이션을 공급자로 제공해서는 안 됩니다.
논리. 프로필은 이러한 힌트를 설명할 수 있습니다. AI 클라이언트는 그것들만 운반합니다.

## 실패 동작

공급자 오류는 다음을 포함하는 구조화된 오류 결과로 정규화되어야 합니다.
공급자 ID, 모델/프로필 ID, 알려진 경우 재시도 가능성 및 사용자 안전
메시지. 누락된 자격 증명은 네트워크 호출 전에 실패 처리되어야 합니다. 지원되지 않음
기능은 자동으로 삭제되는 것이 아니라 기능 오류로 보고되어야 합니다.
도구, 이미지 또는 사고 매개변수.
