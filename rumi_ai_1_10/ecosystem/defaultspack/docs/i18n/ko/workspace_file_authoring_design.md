# 작업 공간 파일 저작 디자인

모든 경로는 작업공간 루트 아래에서 확인됩니다.

운영:

- 목록, 읽기, 검색, 글로브
- 생성, 쓰기, 패치
- 이름 바꾸기, 이동, 삭제
- 차이점 미리보기
- 스냅샷 및 복원
- 유물 저장

쓰기와 유사한 작업은 미리 보기 메타데이터 및 위험 분류를 반환합니다. 삭제, 덮어쓰기, 복원에는 승인이 필요합니다.
