# 메모리 개인화 디자인

메모리 범위:

- 사용자: 지속적인 기본 설정 및 신원 인접 설정.
- 프로젝트: 저장소 또는 작업공간 지침.
- 세션: 임시 작업 사실.
- 파일: 로컬 파일에 연결된 요약입니다.

메모리 유형:

- 선호
- 지시
- 사실
- 스타일
- 결정

사용자 메모리 쓰기 및 메모리 삭제에는 검토가 필요합니다. 프로젝트 구성을 통해 프로젝트 메모리를 가져오거나 내보낼 수 있습니다.
