# デフォルトパックの境界

defaultspack は、Rumi のコア ランタイム パックです。共通の実行を提供します
パックとユーザーデータの表面ですが、具体的なツールのコレクションではありません。
エージェント製品、プロンプト、UI エントリ、またはモデル カタログ。

## Defaultspack に属します

- ランタイム、ブローカー、レジストリ ローダー、アダプター、およびトランスポート コード。
- 機能コントラクト、スキーマ語彙、および汎用実行ブリッジ。
- ツール、プロンプト、プロファイル、プリセット、UI マニフェスト用のパック/user_data ローダー
  プロバイダーのカタログと機能。
- モジュールリスト、パックリクエスト、ポリシーなどのコア管理機能
  レビュー。
- ランタイムの接続に必要な最小限の起動グラフ。

## パックまたはユーザー データに属します

- AI 対応ツールの定義と具体的なツールの実装。
- エージェントの動作プロンプト、プロファイル、プリセット、例、および製品固有
  グラフ。
- 運営会社などの製品プロフィール。
- サイドバー項目、設定セクション、レンダラー、App Shell バリアント、その他
  具体的なフロントエンド宣言。
- プロバイダーおよびモデルのカタログ データ。

## スターター パック

デフォルトのローカル エクスペリエンスは、defaultspack とスターター パックから組み立てられます。

- `rumi_default_tools_pack`: デフォルトのツールマニフェストとツール機能。
- `rumi_local_agent_pack`: ローカル エージェント プロンプト、プロファイル、プリセット、および例。
- `rumi_operations_company_pack`: 運営会社概要、グラフ、ルート、UI。
- `rumi_reference_ui_pack`: サイドバーとパネルのマニフェストを参照します。
- `rumi_model_catalog_pack`: プロバイダー/モデル カタログ マニフェストとプロバイダー UI。

ローダーはインストールされたパックと`user_data`を集約してアタッチする必要があります
可能であれば`source_pack_id`。 defaultspack は非推奨の互換性を維持する可能性があります
エイリアスですが、新しい具体的なコンテンツはパックまたはユーザー データに配置される必要があります。
