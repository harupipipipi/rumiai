# コーディングワークスペース

コーディング ワークスペースは、ローカル ファイル、ターミナル、および
仕事をする。エージェントは、すべての情報を維持しながら、プロジェクト ファイルを検査および変更できます。
構成された 1 つのワークスペースに根ざした操作。

## ルート解決

ワークスペース ルートは、明示的な入力、実行時コンテキスト、
`RUMI_DEFAULTSPACK_WORKSPACE_ROOT`、またはデフォルトのユーザー データ ワークスペース。の
解決されたルートは必要に応じて作成され、パスの権限として扱われます。
小切手。

すべてのファイル パスはそのルートに対して正規化されます。

- 相対パスはルートの下で結合されます。
- 絶対パスは、ルート内で解決される場合にのみ許可されます。
- ルートの外側のパスの横断は拒否されます。
- 返されるパスは、可能な場合はワークスペース相対である必要があります。
