# 外部トークン

外部入力プロバイダーには、検証と送信応答用のシークレットが必要です。
Rumi は、これらの値を書き込み専用の資格情報として扱います。

未加工のトークン値は、UI、API 応答、ログ、監査レコード、
デバッグ ダンプ、生成されたドキュメント、または配信ステータス。

## トークンクラス

|クラス |例 |使用 |
|---|---|---|
|署名の秘密 | Slack署名の秘密、LINEチャンネルの秘密 |インバウンド Webhook を検証する |
|公開検証キー | Discordの公開鍵 |インバウンドインタラクションを検証する |
|アウトバウンドボットトークン | Slackボットトークン、Discordボットトークン、LINEチャンネルアクセストークン |返信を送る |
| Webhook URL | Discord Webhook URL または汎用コールバック シークレット |プロバイダー固有の Webhook メッセージを送信する |
|ローカル取り込みトークン |ゲートウェイ ベアラー トークンまたは Webhook 共有トークン |地元の摂取量を守る |
|返信ハンドル | LINE返信トークン、DiscordインタラクションID/トークン |短期間の応答を送信する |

応答ハンドルは長期間有効な資格情報ではありませんが、依然として資格情報として扱う必要があります。
応答を許可できるため、機密性が高くなります。

## ストレージ

外部プロバイダーの資格情報は、Rumi シークレット ストアまたはプロセスに存在する必要があります。
環境。コードとプロファイルは、生の値ではなく、シークレット名を参照する必要があります。

名前付き外部トークン API は、プロバイダー API キーと同じパターンに従います。

|エンドポイント |行動 |
|---|---|
| `GET /api/external/tokens` |プロバイダー トークンのステータス、マスクされたラベル、種類、エンドポイント リンクを返します。
| `POST /api/external/tokens` | `upsert`、`rename`、または `delete` 名前付きトークン |

名前付きトークンの秘密鍵は `RUMIEXT_{PROVIDER}_{TOKEN_ID}` を使用します。メタデータが保存される
生のシークレットとは別に、プロバイダー ID、トークン ID、表示名、
種類、スコープ、エンドポイント ID、およびタイムスタンプ。

従来の統合シークレット API は互換性のために残されています。

|エンドポイント |行動 |
|---|---|
| `GET /api/integrations/secrets` |プロバイダーのステータスと構成されたキー名のみを返します。
| `POST /api/integrations/secrets` |サポートされているシークレット値を設定またはクリアします。

書き込みエンドポイントは、保存のための取り込みパスであるため、生の値を受け入れます。
秘密。応答はその値をエコーし​​てはなりません。

## 表示ルール

許可される:

```json
{
  "provider_id": "slack",
  "configured": true,
  "configured_keys": ["SLACK_SIGNING_SECRET", "SLACK_BOT_TOKEN"]
}
```

許可されないもの:

```json
{
  "SLACK_BOT_TOKEN": "<raw-token-value>"
}
```

具体的なものがない限り、接頭辞や接尾辞を表示して部分的にマスクしないでください。
オペレータが必要とするため、値を資格情報として使用することはできません。安定したキーを優先する
名前、ハッシュ、作成時間、ローテーションステータス。

## 監査と編集

監査記録には次のものが含まれる場合があります。

- 秘密の名前;
- プロバイダー ID;
- 俳優;
- 操作: 設定、クリア、回転、検証。
- 成功か失敗か。
- 編集されたエラー カテゴリ。

監査記録には以下を含めてはなりません:

- トークン値;
- 認証ヘッダー。
- クッキー;
- 秘密の値に署名する。
- 応答トークン値;
- 認証情報が含まれる場合の完全なプロバイダー リクエスト本文。

## 回転

回転はプロファイルを変更せずにサポートされる必要があります。

1. 新しいシークレットを同じシークレット名で保存します。
2. 受信署名または送信配信を確認します。
3. 古いプロバイダー側の資格情報を削除します。
4. 編集された監査イベントを記録します。

プロファイルはシークレットを参照するため、ローテーション中に編集する必要はありません。
秘密の値ではなく名前です。

## URL プロバイダーはトークンではありません

トンネルまたはイングレス URL は認証情報ではなく構成ですが、それでも可能です。
機密性の高い運用の詳細。 Cloudflare Quick Tunnel は可能な URL の 1 つだけです
開発用プロバイダー。外部入力フレームワークも同じように動作する必要があります
任意のトンネル、リバース プロキシ、またはホストされたイングレスを使用します。
