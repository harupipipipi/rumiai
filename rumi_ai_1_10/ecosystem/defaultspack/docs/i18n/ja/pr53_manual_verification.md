# PR #53 フォローアップマニュアル検証

defaultspack Web アプリを開始した後、ブラウザー UI を使用します。

- 狭い幅と通常の幅: コンポーザー `+` メニューが開き、ビューポート内に留まり、背景から閉じます。
- ファイル添付: ファイルを選択すると、コンポーザーに添付チップが追加されます。
- スラッシュ コマンド: コマンドが使用可能な場合、`/coding` を入力すると、コーディング フロー/モードに切り替わります。
- コーディング フッター: ブランチ、ワークスペース ルート、および選択したファイルがコーディング フッターに表示されます。
- コーディングフッター: フッターから対象フォルダーの変更、ブランチの選択、新規ブランチの作成が可能です。
- `@file`のコーディング: `/coding`で、`@README.md`と入力し、ファイルを選択します。言及は入力に残り、ワークスペース接続チップ/カードが表示されます。
- ワークスペース添付ファイル: 選択したテキスト ファイルを送信すると、ファイル本文がバックエンド ユーザー メッセージ コンテンツに保存されます。バイナリまたはメタデータのみの添付ファイルはメタデータのみのままです。
- 添付のみ送信: テキスト ファイルを添付し、テキスト入力を空のままにして送信します。メッセージは受け入れられ、バックエンド ユーザーのコンテンツには添付テキストが含まれます。
- サイドバーのドラッグ/ドロップ:
  - `composer.toggle_chip`を宣言する`tool_toggle`ウィジェットはコンポーザーチップとなり、オン/オフを切り替えることができます。
  - `composer.action_button` を宣言する `button` ウィジェットはコンポーザー アクション チップになります。 `requires_approval: false` を使用した安全な同一オリジンの `/api/` アクションは、結果をプレビューに表示します。
  - `composer.open_panel` を宣言する `panel` ウィジェットはコンポーザー チップとなり、対応するサイドバー パネルを開きます。
- `composer.selector_chip` を宣言する `selector` ウィジェットはセレクター チップとして受け入れられます。現在の最小限の動作では、パネル/アクション ターゲットを開くことができます。
  - サポートされていないウィジェットの種類、不足している機能、外部エンドポイント、および承認が必要なアクションは無視またはブロックされます。
- 選択されたツール: 選択されたツール ID は、プロバイダー ツールの適応前に `ToolRegistry` を通じて解決されます。生の文字列はプロバイダ `tools` に現れてはなりません。
