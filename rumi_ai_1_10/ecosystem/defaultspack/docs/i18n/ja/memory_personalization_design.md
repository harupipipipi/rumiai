# メモリのパーソナライゼーション設計

メモリスコープ:

- ユーザー: 永続的な設定と ID に隣接した設定。
- プロジェクト: リポジトリまたはワークスペースの指示。
- セッション: 一時的なタスクの事実。
- ファイル: ローカル ファイルに関連付けられた概要。

メモリの種類:

- 好み
- 指示
- 事実
- スタイル
- 決定

ユーザーによるメモリの書き込みとメモリの削除にはレビューが必要です。プロジェクト メモリは、プロジェクト設定とともにインポート/エクスポートできます。
