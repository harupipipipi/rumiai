# UI エージェント エクスペリエンス デザイン

UI はパーツから構築された交換可能なシェルです。

予想されるパネル:

- チャット
- 計画
- ツール呼び出し
- ファイルツリー
- 差分ビューア
- 端子
- アーティファクト
- 記憶
- プロジェクト設定
- 承認ダイアログ
- モデルセレクター
- コンパクトボタン
- 実行履歴
- ソースカード

フロントエンドは、カタログ API から機能、レンダラー、設定、モデル、ツール、アカウントのメタデータを受け取ります。パックの内部をハードコーディングしないでください。
