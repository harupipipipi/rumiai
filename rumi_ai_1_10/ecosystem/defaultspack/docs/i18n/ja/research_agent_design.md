# リサーチエージェントの設計

研究は地元第一主義です。

オブジェクト:

- ソース カード: ローカル ファイル、メモ、Web アーカイブ、公式ドキュメント、GitHub、Reddit、または Web。
- 主張: ステートメント、ソース参照、信頼性、および警告。
- 引用: ソース パスまたは URL への安定した参照。
- 比較表: 構造化された行と列。

事実を主張するには公式文書が優先されます。 Reddit のようなソースはユーザーの音声のみです。 Web、ブラウザ、Reddit プロバイダーはオプションです。
