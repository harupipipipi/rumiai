# ローカルファースト政策

defaultspack コアはクラウド API キーなしで使用できます。

このリポジトリの正規実装は次のとおりです。
`rumi_ai_1_10/ecosystem/defaultspack/`。古い`ecosystem/defaults/` パッケージ
と別個の `harupipipipi/rumiai_defaults` リポジトリには互換性があるか、
スナップショットのソース。新しい実行時の動作、安全ルール、ルート コントラクト、および UI
デフォルトは、レガシーエイリアスを保持したまま、最初にdefaultspackに実装する必要があります
既存の発信者が依然としてそれらを必要とする場合にのみ。

ポリシー:

- パックがより広範な機能を明示的に付与しない限り、ワークスペース ファイルのみ。
- ネットワークはデフォルトで拒否されます。
- クラウド モデル プロバイダーはオプションのアダプターです。
- ファイルの書き込み、上書き、削除、ターミナルの実行、および git プッシュには承認メタデータが必要です。
- シークレットは Rumi シークレット ストアに保存され、UI カタログに公開されることはありません。
- 監査レコードには、アクション、リスク、決定、および編集された引数が含まれます。

コアには、ローカル ファイル、ターミナル、git、ローカル モデル プロバイダー インターフェイス、メモリ、プロジェクト、コンパクト、アーティファクト、安全性、権限、監査が含まれる場合があります。外部検索、Reddit、ブラウザ ネットワーク、GitHub API、SaaS 統合、クラウド スケジュールは引き続きオプションです。

## 実行時のデフォルト

・起動保証機種は`stub/default`です。
- Ollama、LM Studio、vLLM、llama.cpp、local などのローカル プロバイダー
  OpenAI互換エンドポイントは外部ネットワークを作らずに検出可能
  リクエスト。
- クラウド プロバイダーはカタログ エントリおよび構成ターゲットですが、
  新規実行時のデフォルトとして選択されていません。
- ランタイムでの自動クラウドプロバイダー登録は、
  プロセスは`RUMI_DEFAULTSPACK_ENABLE_CLOUD_PROVIDERS` を使用して明示的にオプトインします。
- ローカルプロバイダーには API キーは必要ありません。 API キー プロンプトのみが表示されます。
  クラウド プロバイダーまたはクラウド モデルを選択した後。

## ローカル操作の保護

機密性の高いローカル操作は、ユーザー アカウントとは独立して保護されます。これ
クロスサイトまたは古いタブの変更試行からローカル HTTP ランタイムを保護します
ログイン、アカウント作成、Supabase、または Cloudflare の依存関係を追加する必要はありません。

機密性の高い変更には、ファイルの書き込み/作成/削除/パッチ/復元、ターミナルが含まれます。
実行/ストリーミング、git コミット/プッシュ、統合シークレット、ブラウザー
スクリーンショット。実行前に次のチェックに合格する必要があります。

- クライアント アドレスはループバックです。
- Origin ヘッダーが存在する場合、それはローカルです。
- Origin を持つ敏感な突然変異には、`X-Rumi-CSRF` が含まれます。
- ブロックは、操作にバインドされた署名付きワンタイム承認トークンを受け取ります。
  引数のハッシュ。
- 試み、承認決定、実行、拒否、または失敗は、
  シークレットが編集された JSONL 監査ログ。
