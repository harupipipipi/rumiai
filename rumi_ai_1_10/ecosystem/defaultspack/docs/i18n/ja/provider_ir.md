# プロバイダー IR

Rumi Chat IR v2 は、ChatStore とプロバイダー間のプロバイダー中立の契約です。
アダプター。これにより、defaultspack は従来のものよりも豊富なチャット状態を保存できるようになります。
既存のパブリック API の安定性を維持しながら、OpenAI 風の StandardMessage 形式。

## ストレージ境界

ChatStore はプロバイダーに依存しません。 Rumi メッセージとワークスペースを保存します
プロバイダーのペイロードではなく、アーティファクトです。保存されたメッセージは次のように変換されます。

```text
stored_messages_to_ir(conversation_id, messages)
ir_to_legacy_standard_messages(ir)
legacy_standard_messages_to_ir(messages)
ir_to_stored_messages(ir)
```

`convert_to_standard()` はまだ存在し、IR を通じて委任されているため、古い呼び出し元には次のことが表示されます。
同じ StandardMessage 出力。

## ルミチャット IR v2

IR オブジェクトは明示的な `schema_version` フィールドを保持します。コアモデルには以下が含まれます
`RumiChatIR`、`RumiIRMessage`、`RumiIRBlock`、`RumiToolCallIR`、
`RumiToolResultIR`、`RumiUsageIR`、`RumiResponseIR`、`RumiStreamEventIR`、
`ProviderWarning`、`DroppedFeature`、および`BridgeAction`。

サポートされているブロック タイプには、テキスト、画像、オーディオ、ビデオ、ファイル、PDF、ツール呼び出し、
ツールの結果、推論、引用、イベント、拒否、不明。不明なブロック
保存されています。推論ブロックはデフォルトで内部にあり、挿入されません
モデルが表示可能とマークされていない限り、プロンプトに表示されます。

## 能力と計画

プロバイダー マニフェストは `domain/ai_client/capabilities/manifests/` に存在します。の
レジストリは、マニフェストのデフォルト、ランタイム モデルのメタデータ、および次のような癖をマージします。
トークンパラメータ名、推論動作、ツール名のルール、システムと役割のマッピング、
ストリーム使用法のサポート、プロバイダー ファイル ID、組み込みツール、および MCP ツール。

リクエスト プランナーは、機能をサイレントに削除するのではなく、機能低下を記録します。

- サポートされていない開発者ロール: ラベル付きセクションを持つシステムにマージします。
- サポートされていないシステム ロール: 保護されたプレフィックスを最初のユーザー メッセージに挿入します。
- サポートされていない推論: 推論パラメータを無効にし、ドロップされた機能を記録します。
- サポートされていない画像/PDF/オーディオ/ファイルのアップロード: ブリッジ アクションまたは警告を作成します。
- サポートされていないプロバイダー ツール: プロバイダー ツールを省略し、要求されたツールを記録します。
- サポートされていない並列ツール呼び出し: ツール ループをシリアル化します。
- サポートされていない厳密な JSON スキーマ: ベストエフォート JSON にダウングレードします。
- 無効なプロバイダー ツール名: ツール プロトコル v2 によるエイリアス。

## プロバイダーコンパイラー

Provider Compiler v2 は、計画されたリクエストをプロバイダーのペイロードにコンパイルし、解析します
Rumi 応答 IR に応答を返します。実装されているコンパイラ ファミリは次のとおりです。

- OpenAI チャット;
- OpenAI 応答;
- OpenAI 互換。
- Google OpenAI 互換。
- Google ネイティブの生成 API。
- 人間的なメッセージ;
- 岩盤コンバース。
- ローカル OpenAI 互換。

コンパイラのパスは保護されています。 `RUMI_DEFAULTSPACK_PROVIDER_COMPILER_V2=1` を使用して、
オプトインします。強制的にロールバックするには、`RUMI_DEFAULTSPACK_PROVIDER_LEGACY_MESSAGES=1` を使用します。

## ツール プロトコル v2

Rumi ツールの定義とプロバイダー ツールの定義は別のものです。プロトコル
元の名前とプロバイダーのエイリアスを追跡し、プロバイダー ツールのコールバックをデコードします。
Rumi ツールは呼び出し、ツールの結果を IR ブロックとしてエンコードします。ツールの結果には以下が含まれる場合があります
テキスト、JSON、画像、ファイル、アーティファクト、承認が必要な状態、切り捨て
大規模な出力のメタデータ。

## 添付ファイル/ファイル v2

添付ファイルは従来の `workspace_attachments` メタデータの形式を維持しながら、
会話ワークスペースに添付ファイル v2 マニフェストを書き込みます。アタッチメント
レコードには、ID、名前、MIME タイプ、サイズ、ワークスペース パス、ソース フィールドが含まれます。
表現、プロバイダー参照、作成時間。生の巨大データの URL はサポートされません。
回避可能な場合は履歴メタデータに保存されます。

## プロバイダー トレース

トレース アーティファクトは次の下に書き込まれます。

```text
user_data/shared/chat/conversations/<conversation_id>/workspace/provider_traces/
```

これらには、スキーマのバージョン、リクエスト ID、プロバイダー、モデル、API ファミリ、IR スキーマ、
機能の概要、メタデータの計画、削除された機能、ブリッジ アクション、
警告、サニタイズされたペイロード、応答の概要、およびタイムスタンプ。 APIキー、
認証ヘッダー、トークン、資格情報、パスワード、シークレット、およびイメージ Base64
ペイロードは編集されます。
