# ブラウザコンピュータ使用オプションデザイン

ブラウザとコンピュータの使用はオプションの機能です。

操作:

- ブラウザを開く
- スクリーンショット
- クリック、入力、キー、スクロール
- テキストを抽出する
- ダウンロード
- セッションの保存と復元
- ウィンドウスコープのコンテキストとスクリーンショット
- 中断を伴わない移動/クリックマーカー用の仮想 AI カーソル
- テキスト/キードライバーの自動切り替え:
  - 明示的に要求された場合の Chrome DOM バックグラウンド エントリ
  - ユーザーがオーバーラップを許可した場合のフォアグラウンドキーボードフォールバック
  - Chrome 以外のアプリの通常のフォアグラウンド デスクトップ アクション

ネットワーク ナビゲーション、ダウンロード、外部サイトとのやり取りには承認と監査が必要です。コア カタログにはこの機能が記載されていますが、ブラウザ プロバイダーは必要ありません。
