# 浏览器电脑使用可选设计

浏览器和计算机使用是可选功能。

操作：

- 浏览器打开
- 屏幕截图
- 单击、键入、按键、滚动
- 提取文本
- 下载
- 会话保存和恢复
- 窗口范围的上下文和屏幕截图
- 虚拟 AI 光标，用于无干扰移动/单击标记
- 自动文本/按键驱动程序切换：
  - 明确请求时 Chrome DOM 后台条目
  - 当用户允许重叠时前台键盘回退
  - 非 Chrome 应用程序的正常前台桌面操作

网络导航、下载和外部站点交互需要批准和审核。核心目录描述了此功能，但不需要任何浏览器提供程序。
