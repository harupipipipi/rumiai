# 外部令牌

外部输入提供者需要秘密来进行验证和出站回复。
Rumi 将这些值视为只写凭证。

原始令牌值绝不能显示在 UI、API 响应、日志、审核记录中，
调试转储、生成的文档或交付状态。

## 令牌类

|班级 |示例|使用 |
|---|---|---|
|签约秘笈 | Slack 签名秘笈、LINE 通道秘笈 |验证入站 webhook |
|公共验证密钥 |不和谐公钥 |验证入站交互 |
|出站机器人令牌 | Slack 机器人令牌、Discord 机器人令牌、LINE 通道访问令牌 |发送回复 |
|网络钩子 URL | Discord Webhook URL 或通用回调秘密 |发送特定于提供商的 Webhook 消息 |
|本地摄入令牌|网关承载令牌或 webhook 共享令牌 |保护本地摄入 |
|回复手柄 | LINE 回复令牌、Discord 交互 ID/令牌 |发送短暂的回复 |

回复句柄不是长期有效的凭据，但它们仍然必须被视为
敏感，因为他们可以授权做出回应。

## 存储

外部提供者凭证应存在于 Rumi 秘密存储或进程中
环境。代码和配置文件应引用秘密名称，而不是原始值。

指定的外部令牌 API 遵循与提供者 API 密钥相同的模式：

|端点 |行为 |
|---|---|
| §鲁米§0§|返回提供者令牌状态、屏蔽标签、种类和端点链接 |
| §鲁米§0§| `upsert`、`rename`或`delete`命名令牌 |

命名令牌密钥使用`RUMIEXT_{PROVIDER}_{TOKEN_ID}`。元数据已存储
与原始秘密分开，包括提供者 ID、令牌 ID、显示名称、
种类、范围、端点 ID 和时间戳。

为了兼容性，保留了旧版集成秘密 API：

|端点 |行为 |
|---|---|
| §鲁米§0§|仅返回提供程序状态和配置的键名称 |
| §鲁米§0§|设置或清除支持的秘密值 |

写入端点接受原始值，因为它是保存的摄入路径
一个秘密。响应不得回显该值。

## 显示规则

允许：

```json
{
  "provider_id": "slack",
  "configured": true,
  "configured_keys": ["SLACK_SIGNING_SECRET", "SLACK_BOT_TOKEN"]
}
```

不允许：

```json
{
  "SLACK_BOT_TOKEN": "<raw-token-value>"
}
```

除非有具体的说明，否则切勿通过显示前缀或后缀来部分掩盖
操作员需要且该值不能用作凭证。更喜欢稳定的密钥
名称、哈希值、创建时间和轮换状态。

## 审核和编辑

审计记录可能包括：

- 秘密名字；
- 提供商 ID；
- 演员；
- 操作：设置、清除、旋转、验证；
- 成功或失败；
- 编辑错误类别。

审计记录不得包括：

- 代币价值；
- 授权标头；
- 饼干；
- 签署秘密值；
- 回复令牌值；
- 完整的提供者请求主体（当它们包含凭据时）。

## 旋转

应支持旋转而不更改配置文件：

1. 将新的密钥保存在相同的密钥名称下。
2. 验证传入签名或外向交货。
3. 删除旧的提供商端凭据。
4. 记录经过编辑的审核事件。

配置文件在轮换期间不需要编辑，因为它们引用秘密
名称，而不是秘密值。

## URL 提供者不是令牌

隧道或入口 URL 是配置，而不是凭据，但它们仍然可以
敏感的操作细节。 Cloudflare Quick Tunnel 只是一种可能的 URL
发展的提供者。外部输入框架必须以相同的方式工作
与任何隧道、反向代理或托管入口。
