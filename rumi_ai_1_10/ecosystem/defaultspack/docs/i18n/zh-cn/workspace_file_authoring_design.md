# 工作区文件创作设计

所有路径都在工作区根目录下解析。

操作：

- 列表、读取、搜索、全局
- 创建、编写、修补
- 重命名、移动、删除
- 差异预览
- 快照和恢复
- 神器保存

类似写入的操作返回预览元数据和风险分类。删除、覆盖和恢复需要批准。
