规则：

- 核心功能必须在没有云 API 密钥的情况下工作。
- 网络和外部 SaaS 提供商是可选适配器。
- 文件写入、删除、终端和 git 推送需要策略门。
- UI 从目录 API 接收功能和组件契约，而不是硬编码的假设。
