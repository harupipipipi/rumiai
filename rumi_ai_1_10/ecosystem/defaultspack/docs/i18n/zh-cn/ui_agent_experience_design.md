# UI Agent 体验设计

用户界面是一个由零件构建的可更换外壳。

预期面板：

- 聊天
- 计划
- 工具调用
- 文件树
- 差异查看器
- 终端
- 文物
- 记忆
- 项目设置
- 批准对话框
- 型号选择器
- 紧凑型按钮
- 运行历史记录
- 源卡

前端从目录 API 接收功能、渲染器、设置、模型、工具和帐户元数据。它不应该对包内部进行硬编码。
