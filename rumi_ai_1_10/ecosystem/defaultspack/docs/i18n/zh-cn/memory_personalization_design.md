# 内存个性化设计

内存范围：

- 用户：持久的偏好和身份相关设置。
- 项目：存储库或工作区说明。
- 会话：临时任务事实。
- 文件：与本地文件相关的摘要。

内存类型：

- 偏好
- 说明
- 事实
- 风格
- 决定

用户内存写入和内存删除需要审查。项目内存可以通过项目配置导入/导出。
