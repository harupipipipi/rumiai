# Rumi OpenClaw Parity Pack

This pack records the OpenClaw surfaces that Rumiai should cover as installable
packs. It is intentionally declarative: it does not install npm packages, call
external services, or grant runtime authority by itself.

The catalog maps OpenClaw channels, plugins, providers, skills, runtime
concepts, memory, automation, security, media, and node/canvas surfaces onto
Rumiai pack IDs so setup flows can show what is covered and what still needs a
behavioral implementation.
