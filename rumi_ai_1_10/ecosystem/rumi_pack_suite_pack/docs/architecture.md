# Architecture

The suite pack has three declarative catalogs.

1. Bundle catalog: practical install groupings such as coding, research workspace, browser operator, personal OS, and an operations-oriented integration control plane.
2. Overlap matrix: the owning pack for ambiguous surfaces such as browser execution, artifacts, schedules, connector transport, memory, and model-routing support.
3. Promotion matrix: criteria for deciding whether an optional pack should move into defaultspack or remain optional.

No bundle changes runtime state. Installers and UI can read this pack to present curated choices, but users and maintainers remain in control.
