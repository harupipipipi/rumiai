# Rumi Computer Control Pack Docs

This directory contains pack-specific documentation for `rumi_computer_control_pack`.

## Reading Guide

- [architecture.md](architecture.md): responsibilities, boundaries, directory layout, and runtime contact points.
- [interfaces.md](interfaces.md): profiles, prompts, presets, catalogs, specs, policies, secrets, network posture, grants, and overlap notes.
- [operations.md](operations.md): install expectations, development rules, test command, and common failure modes.

## First Pass

Read this pack as a host-control safety and evidence layer. It helps an agent decide what it must observe before clicking, typing, switching apps, using screenshots, or interpreting terminal sessions. It does not implement control.
