# Rumi AI OS のデフォルトの UI とレイアウト

このドキュメントでは、`defaults` パックによって提供される UI コンポーネントの設計原則と期待事項について詳しく説明し、特にカスタマイズ、ドラッグ アンド ドロップ機能、および動的ツール表示の要件に対処します。

## UI の核となる哲学: アセットによる柔軟性

Rumi AI OS フロントエンドはモノリシック アプリケーションではありません。これは、パックによって提供される「アセット」の集合体です。 `defaults` パックは標準のグリッドとインタラクション モデルを設定しますが、ほぼすべての要素は置き換え可能です。

### アセットベースの UI レジストリ
1. **フロントエンド/バックエンドの分離:** バックエンドはロジック、フロー実行、およびデータ ストレージを処理します。フロントエンドは、パックによって登録されたアセットのレンダリングを独占的に担当します。
2. **アセット カタログ:** パックは、`assets` 配列の下の `ecosystem.json` で UI コンポーネント (カスタム チャット ウィンドウ、新しい入力スタイル、設定パネルなど) を定義します。
3. **UI 設定パック:** 汎用レイアウト資産 (「フルスクリーン レイアウト」、「サイドバー オーバーレイ」など) を宣言する概念的または文字通りのパック (`settings_pack` など) をインストールできます。 `defaults` パックはベースライン グリッドを提供します。

## ドラッグ アンド ドロップ アーキテクチャ

任意の配置の要件を満たすには (チャット ウィンドウや入力フィールドを自由に配置するなど)、次の手順を実行します。

1. **キャンバス コンテナ:** メイン UI は「キャンバス」とみなされます。
2. **ドラッグ可能なコンポーネント:** デフォルト パックのコア入力と出力 (チャット ストリーム、入力バー、ツール ステータス) は、ドラッグ可能なアセット コンテナにラップされています。
3. **位置の永続性:** ユーザーがコンポーネントを移動すると、その新しい `(x, y)` または `grid-area` 座標がユーザーの `user_data` ディレクトリ内の `ui_preferences.json` に保存されます。 `defaults` パックは、リロード時にこれらの座標を尊重します。

## 動的ツールの表示と設定

ツールは、AI が現在何を行っているかをユーザーに通知する必要があります。

### 1. ツールのサイドバー (アクティビティ ログ)
* **目的:** `defaults` パックには、標準のサイドバー アクティビティ ログが含まれています。
* **登録:** AI エージェントが (フロー エンジン経由で) ツールを実行すると、バックエンドが UI イベントを発行します。サイドバーはこれらのイベントをリッスンし、リアルタイムの実行ステータスを表示します (例: 「Web で 'Python ライブラリ' を検索しています...」、「`config.yaml` を読んでいます...」)。
* **可視性:** これにより、ユーザーはメインの会話ストリームを混乱させることなく、AI の現在のコンテキストを理解できるようになります。

### 2. カスタム ツール表示 (ToolDisplay アセット)
一部のツールでは、単なるテキスト ログ以上のものを必要とします (データ視覚化ツール、画像ジェネレーターなど)。
* **`tooldisplay` 登録:** ツール パックは、`type: tooldisplay` としてタグ付けされた特定のフロントエンド アセット (React コンポーネントまたは Web コンポーネント) を登録できます。
* **動的挿入:** このツールが実行されると、`defaults` パックの UI オーケストレーターは、このカスタム アセットをアクティブ ツール領域 (多くの場合、モーダルまたは専用の分割ペイン) に動的に挿入します。

### 3. ツール設定 (ToolSetting アセット)
ユーザーはツールを設定する必要があります (API キーの入力、検索設定の設定など)。
* **`toolsetting` 登録:** ツール パックは、設定用の JSON スキーマまたはカスタム UI アセットを提供します。
* **自動 UI 生成:** デフォルトでは、スキーマのみが提供されている場合、`defaults` パックはスキーマのタイプに基づいて設定フォーム (入力、切り替え) を自動的に生成します。カスタム アセットが提供されている場合は、代わりにそれがレンダリングされます。これには、メインの [設定] パネルの [ツール] カテゴリからアクセスできます。

## アニメーションの標準化

異なるパック間の視覚的な衝突を防ぐには:

1. **アニメーション定数:** `defaults` パックは、トランジション用の標準 CSS 変数を定義します (例: `--rumi-anim-fast: 150ms ease`、`--rumi-anim-medium: 300ms ease-in-out`)。
2. **ガイダンス:** パック開発者は、一貫性のあるエクスペリエンスを維持するために、ツールの表示やカスタム UI アセットにこれらの変数を利用することをドキュメントを通じて強く推奨されます。

## フォールバック メカニズム

カスタム UI アセットのロードに失敗するか、エラーがスローされる場合:
1. **フェイルソフト レンダリング:** `defaults` パックはエラーをキャッチし、問題のコンポーネントを画面から削除し、単純なエラー境界ブロックをレンダリングして、OS の残りの部分 (コア チャットなど) が機能し続けることを保証します。
