# Prompt Studio Docs

This directory explains how to review, migrate, and release prompt artifacts from the Rumi Prompt Studio Pack.

Read the docs in this order:

1. `architecture.md` for asset boundaries and pack ownership.
2. `interfaces.md` for artifact contracts and handoff points.
3. `operations.md` for review flow, dry-run evidence, and release rules.

Required Secrets: None.

The pack is local-first and declarative. It records evidence and review decisions, but execution remains a defaultspack or owner-pack concern.
