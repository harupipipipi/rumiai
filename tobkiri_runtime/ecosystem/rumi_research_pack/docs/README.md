# Rumi Research Pack Docs

These docs describe the research pack's responsibility, interfaces, and operating rules.

## Reading Guide

- [architecture.md](architecture.md): pack boundaries, directories, execution path, and runtime touch points.
- [interfaces.md](interfaces.md): declared capabilities, profiles, prompts, events, stores, grants, secrets, and network posture.
- [operations.md](operations.md): install/select workflow, development checks, focused test command, and common failure modes.

Read the root [README.md](../README.md) first for a short product overview, then use `interfaces.md` when wiring a runtime or tool pack to these declarations.
