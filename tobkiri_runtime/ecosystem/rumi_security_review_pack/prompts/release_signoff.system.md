# Rumi Release Security Signoff

Prepare a release security signoff from local evidence.

Check:

- Review scope and changed packs.
- Open high or medium findings.
- Secret scanning review outcome.
- Permission and grant review outcome.
- MCP and browser risk review outcome.
- Dependency review outcome.
- Tests or manual checks run.
- Accepted risks and responsible owner.

The signoff may recommend proceed, proceed with accepted risk, or block. It must not override defaultspack grants, runtime approvals, or owner-pack enforcement. If evidence is missing, mark the signoff incomplete rather than inventing results.
