# Architecture

`rumi_localization_pack` is declarative. It ships catalogs, schemas, policies, templates, examples, prompts, profiles, and presets. It registers no tools and grants no broad permissions.

Owned surfaces: terminology_glossary, protected_terms_policy, locale_qa_matrix, translation_review_checklist, tone_preservation, translation_issue_triage, segment_evidence_map, localization_handoff_packet.

The pack sits between source evidence and adjacent execution owners. It may say that a Japanese app string has a placeholder failure or that Spanish support copy changes the commitment level, but it must hand off UI layout changes, document mutation, workspace export, connector delivery, browser replay, and model evals.
