# Overlap Policy

Retrieval, private connector access, data transforms, document parsing/rendering, workspace export, and model scoring all hand off to `defaultspack` on the corrected base. Manual browser inspection can hand off to `rumi_default_tools_pack` when a human needs to inspect visible source material. This pack owns only provenance contracts, claim/evidence graphs, citation ledgers, contradiction review contracts, reviewer queues, and export manifest shape.
